# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/rnaefe/chatgpt-wrapper/security/advisories/new). Do not open a public issue containing exploit details, credentials or session data.

Include the affected version, impact and a minimal reproduction using synthetic data. Never send a live browser profile, cookie, token or private conversation. There is no guaranteed response timeline or bug bounty.

Fixes target the latest released version. Older versions do not receive a separate maintenance branch. Read the [threat model, data handling and retention policy](docs/SECURITY.md) before using an authenticated session.
