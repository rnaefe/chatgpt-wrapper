# Wrapper, unwrapped

## Brief and subject

A forty-second product film for developers using MCP clients. Show what Wrapper does and lead to the actual source repository. The soundtrack and verified source material stay intact.

The subject inventory: the name Wrapper; a JSON task envelope; objectives bundled with acceptance criteria; a durable local SQLite queue; one browser task at a time; six capability names; nine MCP tools; content-addressed artifacts; chat display/download links; the actual Istanbul cat output; the recorded TypeScript clamp function; the twelve-sample local queue measurement.

The concept: **Wrapper's task envelope becomes a printed sleeve that opens to reveal its actual output.** The sleeve is an original code-drawn packaging illustration. The image inside it is the actual generated artifact. This is the signature move; the film is recorded media and has no pretend interactive controls.

## Taste Skill direction

Source: [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill), installed as `design-taste-frontend` using the Skills CLI for Codex.

- Direction: `borrowed-category`, “Dressed as something else”.

- Borrowed category: premium print packaging.
- Palette: Olive on bone. Ground `#ecebe7`, surface `#e1dfd9`, ink `#38450f`, secondary ink `#5d683a`.
- Display/text: TikTok Sans variable. Display uses the wide axis at 150 and weight 800. Literal JSON and source code use JetBrains Mono.
- Signature: opening sleeve with a task-to-output crossfade, followed by shutter reveals and contrasting printed fields.
- The original electronic score remains at 120 BPM, with scenes meeting on musical beats.

Three redraw operations were recorded. The original showcase board assumed eight to ten actual rows, which the available recording does not contain. Its first replacement, output slips, still assumed six separate outputs. The final showcase uses the input-half/output-half composition, which matches the actual request and its one code result. Gallery tiles were replaced with one changing frame because only one actual generated image is being shown. The frame opens from a crop to the full artifact; it does not invent more outputs.

This is a fixed 1920×1080 film. The web skill's viewport, input, scroll and four-photo requirements are not represented as video checks. We use its typography, composition, source lint and critique principles, then inspect real rendered frames. No website inspector or independent design jury score is claimed.

## Look-and-fix log

Round one: rendered all seven scenes at representative frames. The opening sleeve, wordmark and code spread read clearly. Three other headings wrapped to three lines, with two colliding with supporting copy. The envelope scene also collapsed to an underfilled single slip. Shortened those three headings to authored two-line titles and made the complete JSON envelope the end state.

Round two: re-rendered the affected scenes and checked the full composition, line counts, type collisions, margins, photo framing and footer contrast. Checks target the actual 1080p delivery frame and reduced-motion version. The house-style lint is also run on the final source.

Self-review uses the skill's design/readability/creativity/content rubric, adapted to film. Final internal assessment after the second look: design 8.0, readability 8.0, subject-specific creativity 7.5 and evidence/content 8.0, weighted 7.9/10. The main remaining limitation is the fixed landscape format: a vertical social cut would need its own composition. These are internal design judgments, not measured product performance or outside awards.
